영상 제작을 시작한다.

1. Skill 도구로 `ai-video-reference-replication:ai-video-reference-replication`(표시 이름: 영상 생성)을 호출한다. 이 명령 자체(`영상생성`)를 다시 호출하지 않는다.
2. 이 플러그인의 설치 위치(`PLUGIN_ROOT`)는 `${CLAUDE_PLUGIN_ROOT}`다. 스킬 문서의 `references/`·`scripts/`·`assets/` 경로는 `${CLAUDE_PLUGIN_ROOT}/skills/ai-video-reference-replication/` 기준이고, 플러그인 공통 문서는 `${CLAUDE_PLUGIN_ROOT}/references/`에 있다. 파일 시스템을 검색해 다른 복사본(특히 Codex용 `ai-video-reference-replication-mac`나 `~/.codex/plugins` 캐시)을 읽지 않는다.
3. 스킬의 `Claude Code 이식판 규칙`과 단계 지도를 그대로 따른다. 먼저 `assets/automation-version.json`으로 버전을 표시하고, 단계 문서 1·2를 읽은 뒤 제작 방식부터 채팅 번호 목록으로 묻는다.

사용자가 함께 준 입력(없으면 비어 있음): $ARGUMENTS
